System: one chip per layer

analog weight grid (capacitors)analog circuit (norm, SiLU, multiplier, hold)digital (memory, attention, converters)

Each layer runs on its own chip; 18 chips hold DeltaNet layers, 6 hold attention layers. The embedding is a row lookup; the output layer is a capacitor grid read by an 8-bit ADC referenced to the peak logit (a winner-take-all circuit would suffice for greedy decoding).

Inside a layer chip

analog weight grid (capacitors)analog circuit (norm, SiLU, multiplier, hold)digital (memory, attention, converters)

Weights never move: each matrix is a fixed grid. Signals stay analog inside the chip and become digital only at the memory blocks and the chip-to-chip link. DeltaNet memory is digital because an analog capacitor memory failed in simulation: every token writes every cell, so thermal noise piles up faster than any practical capacitor can hold it.

The AC capacitor grid

Capacitors instead of resistors: capacitors add no thermal (Johnson) noise, match better (~0.1 %), and their reactive current causes almost no wire voltage drop. Synchronous demodulation also rejects amplifier offsets and 1/f noise. The cost is a carrier generator, modulators and demodulators, and area (~5 µm² per 10 fF capacitor).
