Corrections

2026-10-16: an external review found four issues. (1) The converters around the digital memory were not simulated; (2) capacitor mismatch did not grow for small capacitors as Pelgrom's law requires; (3) the design search crashed for capacitor grids; (4) the numerical checks did not assert. Fixing them also exposed (5) a calibration that took the signal peak from a random subsample, so rails clipped real peaks, and (6) a memory ADC with one range for all channels, which rounded quiet heads away. All are fixed, covered by regression tests, and every number on this site was re-measured afterwards. The design now uses per-head ADC ranges (10 bits) into the memory and 12-bit DACs out of it.

Analog numbers come from the circuit timing and energy model of an unbuilt chip; NVIDIA numbers are scaled from the M3 Max measurement using memory bandwidth and compute specs. Treat all of them as order-of-magnitude.
